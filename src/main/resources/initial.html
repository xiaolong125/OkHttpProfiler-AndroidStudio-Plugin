OkHttp & Ktor Profiler

We don't receive any data from your android device.

The profiler can show requests from OkHttp, Retrofit, and Ktor Client directly in the Android Studio tool window.

For installation you need to include library to your app build.gradle file

implementation 'com.localebro:okhttpprofiler:1.0.8'

and add Interceptor to okHttpClient in code

For OkHttp

Java

OkHttpClient.Builder builder = new OkHttpClient.Builder();
if (BuildConfig.DEBUG) {
 builder.addInterceptor(new OkHttpProfilerInterceptor());
}
OkHttpClient client = builder.build();

Kotlin

val builder = OkHttpClient.Builder()
if (BuildConfig.DEBUG) {
 builder.addInterceptor(OkHttpProfilerInterceptor())
}
val client = builder.build()

For Retrofit

Java

OkHttpClient.Builder builder = new OkHttpClient.Builder();
if (BuildConfig.DEBUG) {
 builder.addInterceptor(new OkHttpProfilerInterceptor());
}
OkHttpClient client = builder.build();
Retrofit retrofit = new Retrofit.Builder()
 ......
 .client(client)
 .build();

Kotlin

val builder = OkHttpClient.Builder()
if (BuildConfig.DEBUG) {
 builder.addInterceptor(OkHttpProfilerInterceptor())
}
val client = builder.build()
val retrofit = Retrofit.Builder()
 ......
 .client(client)
 .build()

For Ktor Client (Kotlin Multiplatform)

maven("https://jitpack.io")
commonMain.dependencies { implementation("com.github.xiaolong125:OkHttpProfiler-AndroidStudio-Plugin:v1.1.0") }

Install the profiler in your shared Ktor client:

val client = HttpClient {
 if (profilerEnabled) {
  install(KtorProfiler)
 }
}

Android writes profiler events to Logcat. iOS writes them to the Apple system log.

More details by link: https://github.com/itkacher/OkHttpProfiler
